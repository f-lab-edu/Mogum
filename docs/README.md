# docs — 머금 설계

2026-11-02 부터 처음부터 다시 설계한 문서다. 처음에는 기존 `docs/` 옆의 `docs-next/` 에서 썼고, 2026-11-08 에 기존 `docs/` 를 지우고 이 묶음으로 바꿨다([교체한 것](#교체한-것-2026-11-08)). 이 설계를 바탕으로 개발을 이어 간다.

**다시 설계하는 이유** — 설계가 잘못된 부분이 있다고 느끼고, 전체 흐름을 확실히 이해하지 못하고 있다. 처음부터 다시 설계하면서 프로젝트에 대한 이해를 확실히 한다.

## 규칙

- 옛 설계 문서는 저장소 기록(`main` `7646433` 까지)에만 있다 — 링크하지 않는다. 필요한 내용은 옮겨 적고, 이미 구현된 사실은 코드를 근거로 쓴다.
- **사용자가 정한 것만 쓴다** — 기존 설계를 전제로 두지 않는다. 2026-11-05 부터 Claude 가 정한 것은 ADR 에 「사용자 확인 전」을 붙이고 위 표에 올린다.
- 이름은 [GLOSSARY](./GLOSSARY.md)가 단일 출처다 — 새 이름은 여기 먼저 넣고, 이름을 바꾸면 GLOSSARY 와 ADR 을 함께 고친다.
