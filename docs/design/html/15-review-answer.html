Q. 핵심 질문
alarm 예정 간격: 1일

TypeScript에서 interface와 type 별칭의 제네릭(<T>) 선언 방식과 선언 병합(Declaration Merging) 지원 여부의 핵심 차이는 무엇인가요?

psychology_alt자신의 생각과 아래 핵심 해설을 비교한 뒤 난이도를 선택해주세요.
verifiedA. 정답 및 핵심 해설
선언 병합 vs 재선언 불가

1. 선언 병합(Declaration Merging): interface는 동일 스코프 내에서 여러 번 선언하면 자동으로 하나의 정의로 합쳐집니다. 반면 type 별칭은 중복 선언 시 'Duplicate identifier' 컴파일 에러가 발생합니다.

2. 제네릭(<T>) 선언 형태 비교: 두 문법 모두 제네릭 매개변수를 지원하지만 할당 방식과 표현력에서 차이가 납니다.

codeinterface Box<T>선언 병합 지원
interface Box<T> {
  value: T;
}
// 동일 이름 재선언 시 병합됨
interface Box<T> {
  tag?: string;
}
data_objecttype Box<T>재선언 불가 (단일 정의)
type Box<T> = {
  value: T;
};
// 재선언 시 에러 발생!
// type Box<T> = ... (Error)
tips_and_updates

실무 권장: 공용 라이브러리나 확장 가능한 객체 API 규격에는 interface를, 유니온(|)·인터섹션·튜플 등 연산 타입에는 type을 사용하는 것이 관례입니다.
