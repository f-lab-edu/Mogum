# 화면 시안 — Stitch 사본

- **출처** — Stitch 프로젝트 「Duolingo Style Character UI」(`projects/14607858306264319539`). 2026-11-07 에 가져왔다. 사용자가 [06 화면](../06-screens.md)(그릴 때는 그 전신인 「05-screens.md」)을 바탕으로 그렸다.
- **방향이지 정답이 아니다**(사용자 결정 2026-11-07) — 디자인과 구조를 이렇게 가 달라는 그림이다. 똑같이 옮기지 않고, 화면마다 다른 아이콘 · 컴포넌트는 TASK 에서 하나로 맞춘다(「시안을 쓰는 법」).
- **무엇이 보이고 무엇을 할 수 있는지는 [06](../06-screens.md)이 정한다.** 06 의 「두지 않는 것」은 디자인에서 더하지 않는다(06 §1) — 아래 「06 이 막은 것」은 시안에 있어도 만들지 않는다.
- **여기서 직접 고치지 않는다.** 시안이 바뀌면 `tools/` 로 다시 가져온다 — 받은 파일은 스크립트가 덮어쓴다(「다시 가져오기」). 사용자가 준 모구미 이미지는 예외다(「모구미 이미지」).

## 시안을 쓰는 법

Stitch 가 화면마다 따로 그려서 같은 역할의 아이콘 · 컴포넌트가 화면마다 다르다. **TASK 는 화면을 하나씩 베끼지 않고, 공통 컴포넌트를 만들어 모든 화면을 같은 모양으로 맞춘다.**

**따른다** — 화면의 구조(영역의 순서와 묶음 · 무엇을 가장 눈에 띄게 하나) · 틀(모바일은 위 바 + 아래 탭 바, 1024px 이상은 사이드바) · 분위기(보라색 머그컵 · 둥근 카드 · 아래에 두께가 있는 눌리는 버튼 · 마스코트).

**하나로 맞춘다**

- 아이콘 — 세트 하나. 지금은 Material Symbols 와 인라인 SVG 가 섞였고, 다섯 탭 아이콘도 화면마다 다르다(코스 `menu_book` · `school` · `auto_stories`, 복습 `cycle` · `style` · `replay` · `quiz` …).
- 컴포넌트 — 버튼 · 카드 · 배지 · 진도 막대 · 위 바 · 탭 바 · 사이드바 · 확인 펼침. 같은 역할이면 하나다. 지금은 버튼의 눌리는 두께가 1~4px, 카드 모서리가 `xl` · `2xl` · `3xl` · `28px` 로 제각각이다.
- 값 — 색 · 글꼴 · 간격 · 모서리 · 그림자는 토큰으로 쓴다. 시안의 임의 값(`text-[11px]` · `shadow-[0_3px_0_0_#5835C4]` …)을 그대로 옮기지 않는다.

**맞추지 않는다** — 픽셀 · 간격의 작은 차이 · 화면끼리 다른 아이콘과 컴포넌트 모양(맞춘 쪽이 맞다) · 예시 데이터와 예시 문구. step 리뷰의 반려 사유가 아니다.

**맞추는 순서** — 처음 화면을 만드는 TASK 가 토큰과 그 TASK 에 필요한 컴포넌트를 정하고, 뒤 TASK 는 그것을 쓰고 새로 필요한 것만 더한다. 화면 하나만을 위한 변형은 만들지 않는다. 정한 것은 UI_GUIDE 에 쌓는다(06 §15.3). 기준을 고를 때는 `guide.md` 를 먼저 본다 — 다섯 탭 아이콘(§3)과 반응형 틀(§4)을 하나로 정해 두었다. (맞추는 순서 — Claude 제안 · 사용자 승인 2026-11-07)

## 모구미 이미지

**모구미 이미지는 사용자가 만든다**(사용자 결정 2026-11-07). 모구미는 머금의 캐릭터다 — 보라색 머그컵 안의 찹쌀떡. 원본을 Stitch 로 만들어서, 같은 곳에서 만들어야 얼굴 · 질감이 같게 나온다. Codex 는 step 안에서 그리지 않는다.

| 파일(`assets/`) | 모습 | 쓰는 곳(시안 기준) | 상태 |
|---|---|---|---|
| `mogumi-reading.png` | 머그컵 안에서 책을 읽는다 | 로고(위 바 · 사이드바, `guide.md` §1.2) · 로그인 전 화면 · 기다리는 화면 · 코스 화면 | 있음 |
| `mogumi-ai-chip.png` | 머그컵 안에서 AI 칩을 든다 | — | 있음 |
| `mogumi-celebrating.png` | 트로피를 들고 축하한다 | 축하 화면 · 코스 다 마침 · 복습 카드 없음 | 요청 — 시안의 그림 주소가 이미 깨졌다 |

**요청하는 법**

- **step 을 쓸 때(Claude)** — 그 step 의 화면에 필요한 모습이 표에 「있음」인지 본다. 없으면 표에 「요청」으로 더하고, phase 를 돌리기 전에 사용자에게 요청한다.
- **step 을 돌릴 때(Codex)** — 표에 없는 모습이 필요해지면 `mogumi-reading.png` 로 자리를 채우고 표에 「요청」 줄을 더한다.
- **받으면** — 사용자가 파일로 주면 `assets/mogumi-{모습}.png` 로 둔다. Stitch 프로젝트에 올렸으면 `tools/fetch.py` 의 `ASSETS` 에 한 줄 더해 받는다. 표를 「있음」으로 바꾼다.

**규격** — 투명 배경 PNG · 지금 모구미와 같은 3D 클레이 질감 · 보라색 머그컵(`m` 로고) · 긴 변 1024px 이상. 화면에 넣을 크기 · 형식은 TASK 에서 정한다.

화면용 책 읽기 사본(`4-account` step 4)은 `frontend/src/assets/mogumi-reading.png` — 긴 변 384px(384×351px), 투명 배경 PNG다. 표시 크기와 줄이는 명령은 [UI_GUIDE §5](../UI_GUIDE.md#5-모구미-사본)를 따른다.

## 담긴 것

| 경로 | 담는 것 |
|---|---|
| `screenshots/{이름}-mobile.png` | 폭 390px(2배 해상도) · 페이지 전체 |
| `screenshots/{이름}-desktop.png` | 폭 1280px · 페이지 전체 |
| `html/{이름}.html` | Stitch 가 만든 화면 원본 — Tailwind(CDN) 마크업 · 예시 문구 |
| `assets/` | 모구미 이미지 원본 — 「모구미 이미지」 |
| `DESIGN.md` | Stitch 디자인 시스템 원문(영어) — 색 · 글꼴 · 모양 · 버튼 |
| `guide.md` | Stitch 디자인 가이드 원문 — 토큰 · 다섯 탭 아이콘 · 반응형 틀 |
| `tools/` | 다시 가져오는 스크립트 — `fetch.py`(받기) · `shoot.mjs`(찍기) |

- 스크린샷은 HTML 을 브라우저(Chromium)로 열어 찍었다. Stitch 의 화면은 반응형 HTML 하나라서 폭만 바꿔 모바일 · 데스크톱을 얻는다 — 1024px 에서 틀이 바뀐다.
- HTML 의 그림 · 글꼴은 외부 주소다(`lh3.googleusercontent.com` · Google Fonts). 주소가 만료되면 브라우저에서 그림이 빠지지만 스크린샷은 남는다. 프로필 사진은 가져올 때부터 깨져 있었다.

## 그리지 않은 것

06 에 있지만 시안이 없다 — 06 의 표대로 만든다.

- 내 정보 탭(§13) — Stitch 에 「내 정보 (Profile)」 가 있지만 숨김 상태라 가져오지 않았다.
- 기다리는 화면의 실패 — 이유 · 다시 시도(일시적일 때만) · 버리기(§6)
- 로드맵 화면의 검토 중 · 진행 중인 로드맵에서 코스를 만드는 중 · 실패한 칸(§8)
- 복습 탭의 카드 지우기 확인(§11)
- 홈의 칸이 비었을 때 · 「지금은 만들 수 없음」 안내(§15.3)

## 공통 틀

- **1024px 미만** — 위에 로고 바(높이 56px), 아래에 다섯 탭 바(홈 · 코스 · 로드맵 · 복습 · 내 정보) — 06 §2.3 그대로다.
- **1024px 이상** — 왼쪽에 폭 256px 사이드바(다섯 탭)와 위 바. 06 이 디자인에 맡긴 「큰 화면의 탭 바」(§15.3)를 시안은 사이드바로 그렸다.
- 로그인 전 네 화면과 처리방침에는 탭이 없다.
- 탭 아이콘 · 사이드바 아래 위젯 · 위 바의 내용이 화면마다 다르다 — 하나로 맞춘다(「시안을 쓰는 법」).
- 색 · 글꼴 값이 세 곳에서 다르다 — `DESIGN.md` 본문(Primary `#7C4DFF` · Plus Jakarta Sans) · `guide.md`(한글은 Pretendard) · HTML 의 `tailwind.config`(`primary` `#632ce5` · `primary-container` `#7c4dff`). 하나로 정하는 것은 UI_GUIDE 를 만들 때다(06 §15.3).
- `DESIGN.md` 는 「데스크톱에서도 폭 440px 가운데」 라고 적었지만, 화면과 `guide.md` §4 는 1024px 이상에서 사이드바 틀이다.

## 다시 가져오기

이 폴더(`design/`)에서 실행한다. `html/` · `screenshots/` 는 비우고 새로 채운다. `DESIGN.md` · `guide.md` · `assets/` 의 Stitch 이미지는 덮어쓰고, 사용자가 파일로 준 모구미 이미지는 그대로 둔다.

```
npm --prefix tools ci                                # 처음 한 번 — Playwright
npm --prefix tools exec -- playwright install chromium  # 처음 한 번 — 브라우저
python3 tools/fetch.py                               # Stitch 에서 받기 — HTML · 가이드 · 디자인 시스템 · 마스코트
npm --prefix tools run shoot                         # 스크린샷 — 폭 390px(2배) · 1280px, 페이지 전체
```

- `fetch.py` 는 `~/.claude.json` 의 Stitch MCP 설정에서 API 키를 읽는다 — `claude mcp add stitch …` 로 먼저 등록한다. 키는 출력하지 않는다. AGENTS.md 「API 키를 읽지 않는다」의 예외로 사용자가 승인했다(2026-11-07) — 사용자가 시안을 다시 가져올 때만 쓴다.
- **가져올 화면은 `fetch.py` 의 `SCREENS`(이름 → Stitch 화면 ID)가 정한다.** 화면 ID 는 Stitch 에서 고쳐도 그대로라, 고친 화면은 그냥 다시 받으면 된다. Stitch 에 숨기지 않은 새 화면이 있으면 `fetch.py` 가 「가져오지 않은 화면」 으로 알려 준다 — 가져오려면 `SCREENS` 에 한 줄 더하고 「화면별 시안」 표도 맞춘다.
- 다 받으면 가져온 날짜(맨 위 「출처」)와 「그리지 않은 것」 · 「06 과 다른 곳」을 다시 맞춘다.
- `shoot.mjs` 는 뷰포트를 페이지 높이로 늘려 찍는다 — 일반 전체 페이지 캡처는 고정된 위 바 · 탭 바를 첫 화면 높이에 찍는다.

가져오는 것 · 가져오지 않는 것:

- 화면이 아닌 것 — 「머금 UI 디자인 가이드 & 컴포넌트 명세서」 → `guide.md` · 프로젝트의 디자인 시스템 → `DESIGN.md` · 모구미 이미지 2장(책 읽기 · AI 칩) → `assets/`.
- 가져오지 않는 것 — 숨김 화면(내 정보 · 옛 홈 · 옛 코스 목록 · 마스코트 시안) · 「Mogum Learning Experience」(로그인 화면과 같은 HTML) · 「05-screens.md」(06 의 전신 사본) · 노트북 모구미(쓰지 않는다 — 사용자 결정 2026-11-07).
