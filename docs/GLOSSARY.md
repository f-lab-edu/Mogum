# 용어 사전

> **이름의 단일 출처.** 화면 · 코드 · 문서가 이 표를 따른다(ADR-008 · ADR-069). 새 이름은 여기 먼저 넣고, 이름을 바꾸면 이 표와 ADR 을 함께 고친다.
> **코드** 칸은 큰 단위의 코드 이름(영어)이다. 테이블 · 칸 · 상태 값의 코드 이름은 [02 §1 · §8](./02-domain-data.md#8-테이블)에 있다(ADR-152). 단위와 관계는 [02 §1](./02-domain-data.md#1-단위와-관계). 「—」은 따로 코드 이름을 두지 않는 것(다른 것의 모음이거나 아직 정하지 않은 것)이다.
