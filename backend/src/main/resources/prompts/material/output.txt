출력은 다음 순서를 지킨다. 머리말이나 출력에 대한 설명은 덧붙이지 않는다.
1. 강의 자료 본문을 마크다운 그대로 쓴다. 본문 전체를 JSON 문자열이나 코드펜스로 감싸지 않는다.
2. 본문이 끝나면 다음 구분 줄을 혼자 한 줄에 정확히 한 번 쓴다. 본문 안에서는 이 구분 줄을 쓰지 않는다.

3. 바로 다음 줄부터 아래 구조의 JSON 객체 하나를 쓴다. JSON을 코드펜스로 감싸거나 뒤에 글을 덧붙이지 않는다.
{"cards":[{"question":"질문?","answer":"답","concepts":[{"name":"이름","definition":"한 줄 정의"}]}]}
본문의 코드·백틱·백슬래시·따옴표는 원문 그대로 쓴다. 구분 줄 뒤 JSON 안의 문자열에만 JSON 이스케이프를 적용한다.
