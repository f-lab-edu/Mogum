# 프롬프트 v5 — ✅ 확정 (2026-10-03, Q198)

> **비교 실측(20 §4)은 이 버전으로 고정한다.** 실측 중에는 고치지 않는다 — 고치면 v6 를 만들고 처음부터 다시 잰다.

v4 에서 **총량 규칙을 빼고**, **이어 쓰기**를 더하고, **모범 답안 말투**를 통일했다.

| 바꾼 것 | 왜 | 근거 |
|---|---|---|
| ① 개념 설명 **합계 규칙(2,500~3,000자)을 뺀다** — 소절별 분량은 유지 | 총량을 맞추면 가장 많이 줄어드는 강의가 **설명이 가장 필요한 강의**(모르는 개념이 많은 강의)다. *"모르는 건 길게"* 와 부딪힌다. 잘림은 상한으로 해결됐다 | Q197 · 파일럿 v4 |
| 본문 출력 상한 7,000 → **8,000** | v4 최대 6,493 — 코드가 많은 강의에 여유가 빠듯했다 | Q197 |
| ② **이어 쓰기** (`continue.txt`) — 잘리면 *"끊긴 곳부터 끝까지"* 1회 | 잘린 강의는 정리 · 확인 질문 · 예고가 빠진다. 처음부터 다시 쓰면 이미 쓴 토큰을 버린다. **assistant prefill 은 Sonnet 5.5 에서 막혀 있어** 사용자 메시지로 요청한다 | Q199 |
| ③ 모범 답안 끝을 **"~해요 · ~예요"** 로 통일 | v4 에서 *"~이다"* 와 *"~입니다"* 가 섞였다 | 파일럿 v4 |
